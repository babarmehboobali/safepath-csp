# SafePath CSP-11 Lesson Content Standard

SafePath lessons use the current CSP11 Examination Blueprint (V.2024.04.24) as the curriculum anchor. BCSP describes its blueprint as the source of domains, tasks, and knowledge/skill statements used for exam development. SafePath is independent study preparation and is not BCSP examCORE.

## Every lesson must teach

1. **What it is** — a short plain-language definition.
2. **Why it matters** — how a safety professional uses the concept.
3. **Core rule** — one sentence to remember.
4. **How it works** — a logical sequence or decision process.
5. **Workplace example** — a realistic application.
6. **CSP decision** — what the professional should choose, verify, or do first.
7. **Common traps** — attractive but weaker/wrong choices.
8. **Exam essentials** — high-value facts and distinctions.
9. **Practice** — lesson-matched questions with explanations.
10. **Calculation method when relevant** — formula, variables, units, worked example, and calculator steps.
11. **BCSP connection** — the exact CSP-11 task code and a simple statement of what the learner should be able to do.

## Plain-language rule

Technical accuracy is not removed. Technical terms are introduced, defined in simple words, and then used correctly. Examples should make the idea understandable to a learner who is new to the topic without watering down CSP-level decision making.

## Question alignment

A lesson drill question must be assigned to the lesson's `classId`. It should test something actually taught in that lesson. Mixed-domain and full mock exams may deliberately combine lessons, but a lesson drill should remain lesson-specific.

## Coverage rule

All 46 CSP-11 task codes are represented in the SafePath lesson catalog. The application now attaches a plain-language task guide to every lesson through its task code, so each lesson can state the BCSP focus and key areas in learner-friendly words.

## Review rule

A lesson is considered content-complete only when its notes, examples, essentials, and questions collectively cover the applicable task statement. A long note is not automatically a complete note. Conversely, a concise note can be complete when it teaches the required knowledge and decision skill clearly.
